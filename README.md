# Automation Hub

Automation Hub is a web-based automation workspace. Version 1 starts with a FastAPI backend, a React frontend, and OpenAI as the primary AI provider.

## Initial scope

- FastAPI backend with health and API routes
- React + TypeScript frontend starter
- OpenAI integration boundary (server-side only)
- Planned Google and Microsoft integration modules
- Human approval required for sensitive actions
- Environment-based configuration; no secrets committed

## Repository status

The initial architecture and starter files are being added in the `feature/v1-foundation` branch. See `docs/ARCHITECTURE.md` and `docs/SECURITY.md` for design details.
